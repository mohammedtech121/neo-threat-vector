# 🚀 NEO Threat Vector

A fast-paced space arcade game built using HTML5 Canvas and Vanilla JavaScript.

## 🌌 About

NEO Threat Vector uses NASA Near-Earth Object (NEO) data to create a space survival experience where players must dodge incoming asteroid threats.

## ✨ Features

- Spaceship controls
- Asteroid avoidance gameplay
- Score tracking
- Live NASA asteroid data integration
- HTML5 Canvas rendering
- Responsive sci-fi interface

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- NASA NEO API

## 🎮 How to Play

1. Open the game.
2. Control your spaceship.
3. Avoid incoming asteroids.
4. Survive as long as possible.
5. Beat your high score.
